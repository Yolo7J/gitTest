GIT COMMAND NOTES
===============================================================================

--set-upstream vs -u:
Both are IDENTICAL - they do exactly the same thing!

$ git push --set-upstream origin feature-work
$ git push -u origin feature-work

"-u" is simply a SHORT FORM (alias) of "--set-upstream"

What they do:
- Sets the upstream (tracking) branch for your local branch
- After using -u once, you can just use "git push" without specifying the remote/branch
- Links your local branch to the remote branch for future push/pull operations

Example:
First time:  git push -u origin feature-work
Future:      git push  (no need to specify origin or branch name)
